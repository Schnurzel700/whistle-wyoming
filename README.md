# Whistle Wyoming

Home Assistant app for [Cactus Whistle](https://cactuscompute.com/whistle) speech-to-text over the Wyoming protocol.

16.9 MB, CPU-only, languages: en, de, fr, es, it, nl, pl.

Install `whistle` from the store, start it (downloads the model on first run), then add it via the Wyoming integration and pick it as pipeline STT.
