# Whistle STT app

Wyoming speech-to-text with Cactus Whistle (16.9 MB, CPU). Languages: en, de, fr, es, it, nl, pl.

First start downloads `whistle.cact` (~17 MB) into app data, then listens on port 10300. Add via Wyoming Protocol integration; it should also be auto-discovered. Set the pipeline STT to Whistle.
